Activity

A dated log of public GitHub work.

This page pulls recent events from the public GitHub proxy — pushes, pull requests, stars, forks — so there is a real-time, linkable record of activity rather than an edited highlight reel.

How it works

  • Events are fetched through the Cloudflare Worker proxy, not the GitHub API directly.
  • Nothing on this page is manually curated — if a recent public event exists, it shows.
  • The activity feed updates on page load, not on a background poll.
