Phelsy — multi-vendor marketplace

A multi-vendor e-commerce platform for African commerce workflows, with a scalable Django API, AWS-deployed infrastructure, and third-party integrations.

DjangoPostgreSQLAWSREST APIReact
RoleSoftware EngineerYear2021StatusActive

Overview

Phelsy is a multi-vendor e-commerce marketplace built for the operational realities of African commerce: trust, payments, logistics, and the workflows vendors and buyers need in practice.

Problem

Marketplaces are usually built for markets with mature payment rails, identity infrastructure, and delivery networks. African commerce has different constraints. A platform that works there has to be built around vendor workflows that match how trade actually happens, and it has to handle trust through practical mechanics rather than assumptions.

Role

Software Engineer (self-employed). Designed, built, and maintained the platform backend, deployed and managed the cloud infrastructure independently, integrated third-party APIs, and drove security remediation.

Architecture

  • A scalable Django web API as the backend core.
  • PostgreSQL for relational data.
  • AWS for cloud infrastructure, deployed and managed independently.
  • A React frontend for the buyer/vendor experience.
  • Third-party APIs integrated to extend platform functionality (payments and supporting services).

Security

Security work on Phelsy went beyond “apply a fix”: identifying and remediating vulnerabilities, and improving the overall application security posture of the platform. The lessons transfer directly to the supply-chain-focused consulting work on this site.

Infrastructure

AWS-based deployment handled end to end: provisioning, configuration, and operation, without a separate platform team.

Challenges

Building a marketplace that vendors actually trust requires handling inventory ownership, multi-vendor reconciliation, and the operational needs of regional commerce — areas where a generic storefront template is not enough.

Status

Actively developed. Details of the current feature surface and roadmap are confirmed with the project directly.
